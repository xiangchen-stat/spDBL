# spDBL: Dynamic Bayesian Learning for Spatiotemporal Mechanistic Models

Provides tools for Bayesian learning of spatiotemporal dynamical
mechanistic models, including methods for parameter estimation,
simulation, and inference using hierarchical and state-space modelling
approaches. Core computational routines (forward filter, backward
sampler, matrix-normal sampling) are implemented in C++ via RcppEigen.
